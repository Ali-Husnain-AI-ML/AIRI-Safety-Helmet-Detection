# AIRI PITB - AI Internship Task 1

# Project Title
Safety Helmet Detection System Using YOLOv8

## Phase 1 - Problem Selection

### 1. What objects will the system detect?
The system will detect:
- Person
- Helmet
- No Helmet

### 2. Why is this problem useful?
Safety helmets help protect workers from head injuries.
This system aims to identify workers who are not wearing
safety helmets.

### 3. Where can this system be applied?
- Construction sites
- Industrial workplaces
- Factories
- Workplace safety monitoring

### 4. What are the target classes?
1. person
2. helmet
3. no_helmet

### 5. What will be the final output?
A trained YOLOv8 object detection model that identifies
people, helmets and no-helmet cases using bounding boxes,
predicted labels and confidence scores.
